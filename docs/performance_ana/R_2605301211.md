## 5. 方法论沉淀：污染识别与复测协议

本轮固化一条观测纪律，供后续轮次复用：

- **污染标志（出现即怀疑整批）**：`ext:cpp`（ext-index 路径）> 500ms，或短查询缓存 `x` > 10ms——两者物理上不应由数据冷化产生，是系统级停顿的指示器。
- **复测协议**：发现污染标志后，对受影响的 pure-filter / 数值路径做 ≥3× 复测取中位，再据洁净值计算 ns/槽与二层间隙。
- **判定**：恢复常态 → 瞬时污染（丢弃电池值用复测值）；持续偏高 → 真实冷化（保留）。

此协议把"单点异常误判为机制破裂"的风险降到最低，是对历轮"诚实修正"纪律的工具化补强。

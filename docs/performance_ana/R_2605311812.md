5. **查询超时/熔断**：path 1921ms 再次证明用户可见查询可秒级阻塞。

## 11. 结论

- **定性**：🔴 电池避峰但底层风暴升级。18:10 35.9s rewrite 超过 17:42 主峰。
- **分裂**：**52/52** 维持；稳健对抗 1.31×，若用 content W2 低点则 1.02× 贴线。
- **关键发现**：
  - R125 trigram 污染已恢复，电池无 ≥500ms；但这不是系统恢复。
  - 18:10 新主峰后，floor/reprobe 捕获 size 669ms、path 1921ms。
  - 墓碑 1.249M/18.64%，运行期 compaction 仍为 0。
- **根因判断**：不可回收墓碑继续推高 rewrite 成本，flush storm 以簇状间歇复发；查询延迟的强相位依赖仍未解除。
- **行动建议**：不要被本轮干净电池误导；必须优先做比率阀 reclaim 与 storm guard，再做 dm mlock 和 lock-free snapshot flush。

- **分裂 39/39**：四估计法（字面 3.44× / path 锚 4.10× / 中文 4.18× / 对抗 1.60×）全 HOLDS，温冷态下数值层 dm 5.86、字符串层 content 20.17——字符串层冷得更厉害（散布度惩罚），数值层冷度有限，正是「内存散布度主导字符串成本」的预期。

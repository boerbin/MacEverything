## 10. P0 优化建议

1. **下调 `:159` 比率阀 0.25→8–10%**：墓碑 18.06%，连续 15 轮运行期 compaction=0。阀门仍是唯一结构阻断点。
2. **加入 flush storm guard**：当过去 10 分钟内出现 ≥3 次 rewrite>5s 或任一 rewrite>10s，降低 flush 频率/合并写入/暂停非关键 rewrite，避免 33.8s→17.5s→15.9s 连锁。
3. **mlock dm 列**：dm 仍 52–109ms 混合高位，是对抗口径最脆弱层。
4. **lock-free snapshot flush**：相位依赖来自读写锁/页态耦合，必须解耦。
5. **查询超时/熔断**：上一轮 README 8.1s 已证明需要上层保护。

- **定性**：🔴 风暴簇持续，但本轮查询电池避开秒级窗口。
- **分裂**：**49/49** 维持，对抗 1.16×，仍窄。

  - R_2605311612 秒级电池是相位命中，不是算法永久退化；R123 电池亚秒级证明可恢复。

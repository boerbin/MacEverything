## 10. P0 优化建议

1. **立即下调 `:159` 比率阀 0.25→8–10%**：本轮墓碑 17.85%，单轮新增 53,920，风暴复发。继续等待将把 flush 簇推向更高峰值。
2. **dm 列 mlock/madvise**：风暴后 dm 仍 70–100ms 常态，最先失守。约 6.63M × 8B ≈ 53MB，成本明确。
3. **lock-free snapshot flush**：33.8s/17.5s/15.9s flush 直接造成秒级查询。读写解耦是防止全局锁噪声压平所有路径的根因修复。
4. **flush 背压/节流**：当连续 rewrite >10s 时，应暂停或合并后续 flush，避免 33.8s→17.5s→15.9s 级联。
5. **查询超时/熔断**：README 8.1s、.pdf 4.6s 应被上层超时保护。

  - 会话 ≥5s flush 36→44，≥10s 6→9。

- **根因判断**：风暴复发与墓碑增长同步，运行期 compaction 仍为 0。`:159` 阀门是唯一结构性阻断点。

## 3. 本轮关键观察：分区页温度再现（content 冷 + path 暖同轮并存）

**现象**：content 刷新历史新高（40.88，前值上限 38.7@R78），但 path 反而从 38.17 跌到 31.88。

**为什么这不是全局退化**：若是全局退化，所有字符串路径会同向上升。本轮 **content 单路上升、path 反向下降**，是分区独立冷热的教科书式信号：

- `content:import` 走 `pure-filter-soa-gcd`，全量扫 **content 列 SoA 区**；
- `path:/Users` 走 `advanced-linear-gcd`，扫 **path/name 串池区**；
- 两者扫描的页区不同 → 页缓存驻留独立演化 → 本轮恰好 content 区被换出（冷）、path 区仍驻留（暖）。

这正是 **R81「页温度是分区的、非全局的」** 的又一次独立复现，且本轮方向与多数历史轮相反（历史多见 path 冷），进一步证明冷热分配是随机的逐区事件，而非某条路径的固有劣化。

## 6. 问题清单

### 观察项：午后日间 page cache 压力

- **现象**：所有 trigram 路径全面劣化（均值 27→168ms），全扫描路径轻度上升（621→738ms）。

- **严重程度**：轻度——仅 1/16 >500ms（且仅 575ms，刚过阈值），无崩溃性指标。
- **与此前事件对比**：R181（7193ms）和 R176（2217ms）是灾难级，本轮是正常日间波动的上端。
- **预计**：1 轮恢复（R183→R184 battery 已预热部分 postings）。

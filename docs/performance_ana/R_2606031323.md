### Critical：tombstone 连续 2 轮超过 2%（2.36%，138,290 条）

- 证据：
  ```
  R59: 114,858 (1.97%) → R60: 128,261 (2.19%) → R61: 138,290 (2.36%)
  ```
- 本轮增量 10,029 条。增速略缓但总量持续攀升。
- SKIPFLUSH=84，每 5 分钟一次，flush-triggered compaction 完全不可用。
- **tombstone 占用内存**：138K 条 × 每条约 200-400 字节 ≈ 28-55MB 额外内存开销。
- **性能影响**：phase2 扫描遍历 totalRecords（含 tombstone），138K 条约占 2.36% 额外扫描开销。目前尚在可接受范围，但持续增长将线性增加查询成本。

- 本轮 252ms 属于正常区间，但前 3 轮连续 >400ms 表明在 I/O 压力下容易退化。

## 11. 结论

- **定性**：🟠 查询侧干净，但底层 5s 级 rewrite 风暴继续；系统没有结构恢复。
- **分裂**：clean/stable 口径 **56/56** 维持；对抗口径 1.09×，再次贴线。
- **关键发现**：
  - 电池、W1/W2、再探均无新增 ≥500ms 查询。
  - trigram 全线毫秒级，R129 的轻量 trigram 抬升已消退。
  - flush ≥5s 67→71，新增四次 5–8s rewrite。
  - 墓碑 1.297M/19.21%，运行期 compaction 仍为 0。
- **根因判断**：不可回收墓碑持续扩大 rewrite/扫描边界；查询采样是否慢由 flush/页态相位决定。本轮只是避开强污染窗。
- **行动建议**：比率阀 reclaim + storm guard 仍是 P0；dm 驻留与 lock-free snapshot flush 必须紧随其后，避免下一次 5s rewrite 簇再次演化成 10s/30s 主峰并污染读路径。

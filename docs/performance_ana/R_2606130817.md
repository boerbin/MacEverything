## 6. 问题清单

### P0：tombstone 继续逼近 13%

- 证据：tombstone=781,611（12.86%），较上一轮增加 6,858。
- 影响：无效记录比例继续升高，会放大扫描成本、索引重写成本与 compaction 压力。
- 判断：本轮前台扫描回落不能说明根因改善，tombstone 仍在稳定上行。

### P0：最新常规 flush 升至 5.3 秒

- 证据：最新 flush total=5363ms，较上一轮 4654ms 继续上升；`FLUSH=670`，较上一轮 +12；`SKIPFLUSH=0`。
- 影响：完整重写继续以高频率运行，且单次常规 flush 已进入 5 秒级，会持续污染 page cache 并增加前台尾延迟波动概率。
- 判断：flush 仍是当前最明确的系统性瓶颈，缺少退避、增量化和前台保护。

### P0：latest session 仍包含灾难级 flush outlier

- 证据：13:02 flush total=2,285,536ms，03:15 flush total=896,053ms，23:24 flush total=735,223ms，19:06 flush total=107,008ms。
- 影响：持久化路径缺少切分、退避和前台保护，是当前最主要的系统性风险。

### P1：扫描类路径本轮回落但仍是尾部来源

- 证据：`content:import`=179.1ms，`path:/Users`=161.7ms，`中文测试`=142.0ms。
- 影响：本轮无 >500ms，但最高项仍来自 pure-filter 和 linear-gcd，且历史同类查询已多次突破 500ms。
- 判断：扫描路径受 tombstone、page cache 和后台 flush 状态影响较大，需要结构性剪枝而不是只观察均值。

### P1：trigram/indexed 路径整体健康但候选量仍大

## 7. 优化建议

### P0：立即提前或分段 compaction

- 不等待更高的全局 tombstone 阈值；结合绝对 tombstone 数、segment tombstone 率和 flush rewrite 成本触发局部 compaction。
- 优先处理 tombstone 密集 segment，避免 scan/filter 路径继续扫描大量无效记录。
- 验收：tombstone 率从 12%+ 回落，`content:import`、`path:/Users`、`中文测试` 稳定 <200-300ms，full-scan 总和持续下降。

### P0：flush 改为增量/COW 页写入

- 将 stable segment 与 delta segment 分离，常规 flush 只追加或替换小段 delta。
- 大段合并放到后台低优先级任务，不与前台查询争抢热页或持锁窗口。
- 验收：常规 flush total <200ms，latest session 不再出现分钟级 rewrite outlier，lockWait 不再出现 50ms+。

### P0：增加 flush I/O 压力退避和前台保护

- 当最近 flush 超过阈值时，提高下一次 flush 间隔或降低 batch 频率。
- 前台查询活跃或 I/O 延迟升高时推迟大 flush。
- 持久化线程使用低 QoS，并评估大顺序写的 `F_NOCACHE`/同类策略，减少对搜索热页的冲刷。

### P1：为 scan/filter 路径增加剪枝

- 对中文、路径、content/filter 类查询记录扫描记录数和跳过原因，评估轻量字符 n-gram、路径分段、预过滤位图或 segment-level skip list。
- 要求保持内存增长可控，优先使用按需或压缩结构，而不是常驻大索引。
- 验收：`content:import`、`path:/Users`、`中文测试` 在 tombstone 上升期间仍稳定低于 300ms，并能解释每次扫描规模。

### P1：补充 lockWait 与后台状态关联观测

- 记录每次查询锁等待对应的 flush/update 状态、持锁线程、等待阶段和持锁耗时。
- 验收：解释历史 `content:import` 67.6ms lockWait 是 flush、索引更新还是其他写路径导致。

### P1：拆分扫描路径和 trigram 路径耗时

- 对扫描路径记录扫描记录数、tombstone 跳过数、过滤耗时、排序耗时和结果组装耗时。
- 对 trigram 路径记录 postings 读取、候选集交并、排序、路径加载和结果组装耗时。
- 验收：能解释 scan/filter 100-300ms 与 trigram 偶发差值。

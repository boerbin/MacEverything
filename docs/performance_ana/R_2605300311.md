### 解读（第二次诚实修正）

- **R77「size 单调上漂」彻底死亡**：post-R77-peak（9.22）已连降两轮 7.63→6.06，本轮 6.06 是史上最低。若强行找趋势，现在是「降」，但更合理的解释见下。
- **R76「细粒度方差排序」经六样本证伪**：R76 以三样本宣称 size(1.08×)<content(1.28×)<path(1.51×)<dm(1.56×)<中文(1.74×)，单调对应「串池触达足迹」。六样本下极差变为 size 1.52× / content 1.46× / path 1.51× / dm **2.24×** / 中文 1.74×——排序乱成 content<path<size<中文<dm，`size` 不再最小、`dm`（纯数值！）反而最大。**那个干净排序是三样本假象，多采三点就散了**（与 R77 同类教训）。
- **普暖轮的统一解释**：本轮 size(6.06)/dm(9.96)/content(26.6) 同步触及各自历史最低，`hello world` 暖回、`main.cpp` 0.89ms 史上最暖——**整轮页全面变暖，所有路径一起下沉**。这正是「页驻留是公共驱动」的最佳佐证：暖则同暖、冷则各异。
- **唯一稳健且有机制支撑的结论——绝对二层分离**：纯数值（size/dm，跨六样本 6–22 ns/槽）始终 ≪ 字符串 full-eval（content/path/中文，26–54 ns/槽）。机制清楚：前者比较一列 i64、零解引用；后者每条 live 记录解引用串池。两层各自 warm-warm 抖动 ~1.5–2.2×、无干净排序，统一由页温度驱动。

> 结论（跨 R74→R79 收敛）：线性/纯过滤路径稳健事实 = **绝对二层分离（数值层 ≪ 字符串层，机制确定）** + **每层 ~1.5–2.2× 页温度抖动（无干净子排序）**。R74「ns/槽 恒定」、R76「细粒度方差排序」、R77「数值单调上漂」三个推测性子结论先后被更多样本证伪——保留的只剩二层绝对分离与页驻留公共机制。**mlock/madvise P0 同治 trigram 与两层 full-eval。**

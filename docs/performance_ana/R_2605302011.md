## 5. 绝对二层分裂：30/30 经 content 锚成立（字面 min 对抗连续第二轮失败）

**多重稳健性（退回锚，R100/R103 同型）**：
1. **字面 min floor**：path 10.64 > dm 5.19 → 2.05×（floor 层面成立）
2. **字面 min 对抗检验**：dm 最差洁净（W2 簇上沿 72.01ms=11.81ns）vs path 10.64 = **0.9× ❌ FAILS**——path 字面 min 非平稳（1.86×），W2 floor 不可靠（R100 先例）。
3. **平稳锚 floor**：content 15.54 > dm 5.19 → **2.99× ✅**（content 摆动 1.5×，最可信）。
4. **平稳锚对抗检验**：dm 最差洁净 11.81ns < content 15.54 → **1.32× ✅ HOLDS**。

**判定逻辑**：与 R103 同型——字面 min path（10.64）被 dm 最差洁净（11.81）反超（0.9×），但 path 已独立证明非平稳（1.86×），其 floor 不可信，按 R100 协议退回 content 平稳锚。锚解读 floor 2.99× / 对抗 1.32× 双双 HOLDS——**30/30 经锚成立**。

**诚实边界**：这是 R100/R103 之后**第三轮字面 min 失败、靠锚成立**的轮次。dm 最差洁净（11.81）逼近 path 字面 min（10.64）的现象，本轮可直接归因于 **W2 极端突发**——同一窗口 size/path 突发至 3000+ms，dm 簇上沿 72ms 含残余争用，而 path W2 floor 120.72ms（甚至高于 W1 64.86）说明 path 本身被突发污染。两者数值接近是**突发期的混合争用**，非机制层级接近。**content 锚（紧凑串列、摆动 1.5×、不受突发影响）提供干净下界**，分裂机制（纯数值零解引用 ≪ 字符串解引用散布串池）稳固，且本轮 W2「size/path 突发 3000+ms 而 dm/content 纹丝不动」是分裂为锁加性而非机制混淆的最强反证。

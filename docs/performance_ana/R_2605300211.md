### 解读（在 R75/R76 基础上锐化，标注不确定性）

1. **拆分仍成立**：`size`（纯数值）极差 1.16× 仍是所有路径中最小，远小于字符串路径（1.28–1.74×）。「数值地板方差最小 / 字符串覆盖层方差最大」不变。
2. **新兴信号——地板并非纯平**：`size` 四读数**严格单调上升 +16%**，而总记录仅增 0.28%、tombstone 上升（理应降低均摊），二者都不能解释。最可能的解释：**会话变长 / SoA 数值列（append-only 增长，~46MB）随驻留集覆盖度下降而轻微页变冷**——即 page residency 这一普适机制在最致密的纯数值列上也有微弱表现。`dm:today`（另一纯数值路径）亦偏上漂（含噪），方向一致。
3. **字符串路径无单调趋势**：`中文/path/content` 四读数高方差振荡、无明显走向——散落串池页温度在查询间混沌起伏，掩盖任何缓慢趋势，量级也更大。
4. **不确定性声明（遵循「不轻易下结论」）**：size 单调性仅基于 **4 个点**（4 点随机严格单调概率 ~4%，有一定可信度但非定论）。需 R78+ 持续采样确认：① 上漂是否持续；② 若发生重启/全量压缩，size 是否复位（若复位，则坐实「驻留集随会话退化」假说；若不复位，则另有原因）。**本轮仅将其列为待验证的新兴信号，不据此调整 P0 优先级。**

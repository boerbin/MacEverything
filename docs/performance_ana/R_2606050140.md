## 7. 优化建议

### P1：降低 Compaction 阈值至 15%

- 两次周期证明：系统在 17-25% 区间性能严重退化（1-2 小时）。
- **15% 阈值**将退化窗口从 ~1.5 小时缩短至 ~20 分钟。
- **compaction 本身仅 3.6 分钟**——更频繁触发的代价极小。

### P1：GCD 队列优先级隔离

- 即使当前 flush rewrite 仅 2 秒，未来事件风暴期仍会膨胀至 10-40 秒。
- **提前隔离**可在下一次退化周期时保护查询性能。

### P2：Compaction 后主动 page cache 预热

- 当前 `content:import`=289ms（vs R115=65ms）——compaction 后 page cache 需时间恢复。
- **方案**：compaction 完成后立即 `mmap` + `madvise(WILLNEED)` 预读整个新索引。
- **预期**：将 R119 的全表扫描从 ~250ms 进一步降至 ~60ms。

### P3：事件流突发检测与自适应

- 两次周期都由突发事件流（12,000-24,000/min）驱动。
- **方案**：当检测到事件增速 >10,000/min 时，提前降低 flush 频率，避免 I/O 叠加。

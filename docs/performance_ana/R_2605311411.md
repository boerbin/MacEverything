## 11. 结论

- **定性**：🟡 风暴后热平衡态——绝对性能全面退化，相对分裂维持。
- **分裂**：**45/45**（全局地板口径 3.26×，对抗 1.47× 回宽）。对抗回宽原因是字符串层同步上升（+33%），非 dm 改善——「好消息中的坏消息」。
- **关键发现**：
  - **dm 双窗全面升档**：W1 7/8≥74ms + W2 7/8≥71ms，119 轮首次无正常窗。
  - **R119→R120 W1 地板全面退化**：5 查询 W1 地板均恶化 1.17–2.28×。R119 的 W1 热态不可重现。
  - **风暴后损害持久化**：无活跃 ≥5s flush（最近 2.4–3.1s 正常），但基线未回落。R117 风暴→R119 降温→R120 新平衡，三阶段页态演化完整。
  - **两层同升维持比值**：dm 升档同时 content 也从 109→145ms → 对抗从 1.06→1.47×。这不是改善，是退化均摊。
- **入墓比 98.3%**——几乎所有 I/O 都在创建不可回收的墓碑。活记录冻结（5,447,088 几乎不动），死记录单调增长。
- **治本路径不变**：比率阀 + mlock + lock-free flush。当前最紧迫：风暴后基线不自行恢复证明必须主动钉页，被动依赖 OS 页管理已不可行。

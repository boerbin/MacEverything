## 3. 问题诊断

### 3.1 【P0】墓碑占比 23%，compaction 从未触发

31h 内 live 仅增 73k，墓碑从 342k 膨胀到 1.57M。日志显示 `Auto-compaction started (initial interval 300s)` 但全程无一 compaction 完成日志。线性扫描路径（`.h` 走 linear-gcd）多扫 23% 死记录，时延 ×1.23。compaction 触发条件需审查——可能仅按时间阈值 300s，被 flush 风暴永远打断。

### 3.2 【P0】Flush 风暴：90% 的 flush <60s，配置 300s 形同虚设

2,481 次 flush / 31h = 每 45s 一次，89% 在 60s 内。每次序列化写 6.8M 记录，写放大数十 GB/天。89% 的 flush 集中在 <60s 窗口，说明事件触发（FSEvents 5M+ 文件）阈值远低于时间触发，两者未 coalesce。

**二级影响**：flush 与查询在 `IndexLock` 上互斥，解释了 §1 中 HTTP 端 2~3.5s 的抖动（首跑 472ms → HTTP 3562ms，差值即锁等待）。

### 3.3 【P0】"Failed to flush paged index" ERROR ×7，根因现场全缺

```
18:20:13  ERROR  18:22:26  ERROR  05:38:00  ERROR
05:38:03  ERROR  11:39:31  ERROR  17:37:00  ERROR  17:37:06  ERROR
```

7 次、分 4 个时间簇。错误信息仅一句兜底，无 errno、path、freeBytes、调用阶段。paged index 失败 → ShortQueryCache 等增量结构可能停留在旧版本。

### 3.4 【P1】扩展名重查询 HTTP 端到端 1~3s

`.h` 内部计时 200~472ms，HTTP 端 1.8~3.5s。差值 = 序列化 + HTTP 响应构建 + 锁等待。扩展名是最常见查询类型之一，热路径走 linear-gcd O(N)。

### 3.5 【P1】AI 翻译质量：`图片→pic:` 残缺、`项目中cpp文件→content:cpp` 语义错误

prompt 占 68% 上下文（1392/2048 tokens），生成空间不足。`pic:` 非合法 filter，`content:cpp` 应走 `ext:cpp` 但内容索引为空（`ContentIndexedFileCount=0`）。

### 3.6 【P1】括号解析 bug — `test (1)` 类文件完全不可搜

QueryParser 把 `(` / `)` 当语法 token（分组/通配），未作字面量 escape。macOS Finder 自动重命名大量产生 `xxx (1).xxx` 格式。

### 3.7 【P2】Content 索引从未构建

`No base content index found at .../content_index.bin` + `contentIndexedFileCount=0`。`Auto-compaction started (event-driven)` 但无后续 flush 日志。内容搜索功能全量不可用。

## 4. 优化建议

| 优先级 | 行动项 | 预期收益 | 成本 |
|---|---|---|---|
| **P0** | flush 限流：`min_interval=300s` 硬下限或 token-bucket，事件触发 debounce | 写盘降 5×，锁竞争消除 | S |
| **P0** | ERROR 补全：`errno`/`strerror`/`path`/`freeBytes`/`stage` | 让 #3.3 可定位 | XS |
| **P0** | compaction 按墓碑比例 ≥15% 触发（不只是时间） | 线性查询提速 1.25× | S |
| **P0** | QueryParser 括号当字面量（非高级语法时） | 修一类文件搜不到 | S |
| **P1** | 扩展名倒排索引 `ext→vector<recordIdx>` | `.h` 类查询 300ms→<10ms | M |
| **P1** | HTTP 访问日志：每请求一行 `method path latency results` | 可观测性 | S |
| **P1** | shared_lock 分离 search/flush | 时延抖动归零 | M |
| **P1** | AI prompt 精简至 20 few-shot，fix 错误样本 | infer p95 降 ~30% | S |

| **P2** | 内容索引首次构建触发（config 开启后） | 内容搜索可用 | M |

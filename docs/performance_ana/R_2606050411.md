### Page cache 动态平衡机制

| 因素 | 效果 |
|------|------|
| OS 内存回收 | page cache 页面被释放 → 全表扫描变慢 |
| flush 重写（每 30s） | 写入索引文件 → 部分页面留在 cache |
| Query battery（每 30min） | 16 次查询读取索引 → 触发 page cache 填充 |
| **净效果** | 300-500ms 区间震荡，不会无限退化 |

- **R123 的 495ms 是偶发峰值，不是持续趋势。**
- **系统在深夜形成稳态**：OS 回收 vs flush+查询预热 → 平衡点 ~350-460ms。

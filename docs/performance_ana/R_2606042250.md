## 7. 优化建议

### P1：GCD 队列优先级隔离（flush vs 查询）

- 仍有偶发秒级 GCD 延迟——flush rewrite 占用 GCD 线程池。
- **方案**：查询使用 `QOS_CLASS_USER_INTERACTIVE`，flush 使用 `QOS_CLASS_UTILITY`。

### P1：Flush 频率进一步限制

- 当前 3.7 次/小时（已大幅改善），但每次 3-9 秒 rewrite 仍偶尔影响查询。
- **方案**：增加最小间隔 10 分钟（~6 次/小时上限）。

### P2：linear-gcd 路径优化

- `path:/Users` 和 `中文测试` 的 phase2 依赖全表扫描——结构性问题。

### P2：降低 compaction 阈值

- 当前 25%——建议降至 5-10%，使 compaction 更频繁但更快。

## 6. 问题清单

### High：`.pdf` 查询高波动（208ms ↔ 4091ms ↔ 9221ms）

- 证据：三轮数据 9221 → 208 → 4091ms。phase2 耗时 4031ms。
- 根因：`.pdf` trigram 候选数多（~9881），phase2 验证需逐条读取文件名做精确匹配。当后台 FSWatcher/flush 活跃时，I/O 竞争导致 phase2 延迟倍增。
- 结构性问题：`.xxx` 扩展名查询不应走 trigram 路径。

### Medium：`hello world` 持续偏慢（422-545ms）

- 证据：三轮 474 → 422 → 545ms。phase2=541ms。
- 多词 trigram 查询的 candidate 验证成本稳定偏高。

### Medium：DIAG-TRIGRAM SKIP 持续积累（55 次）

- 仍以 1/轮 的速度增加。

### Low：tombstone 缓慢增长（17,015 条）

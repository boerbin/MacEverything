### 解读（三样本一致）

- **`size:>100m` 是稳定地板**：三读数 7.95–8.58 ns/槽，极差 1.08%——纯数值单列比较、零字符串解引用，扫描的 `types_`/数值列每次都被触达、始终驻留。这坐实「O(N) 数值地板稳定」。
- **方差随「字符串/页触达足迹」单调上升**：size(1.08×) < content(1.28×) < path(1.51×) ≈ dm(1.56×) < 中文(1.74×)。`中文`（CJK 无 trigram → 0 命中 → 全比对每条 live 名字、无早退）触达最多串池页，方差最大。
- **R74「ns/槽 恒定」被三样本证伪**：`中文` 实测 31–54 ns/槽，并非常数。R75 的「地板稳 / 覆盖层抖」拆分在第三个独立样本下成立。

> 结论（与 R75 一致并加强）：线性/纯过滤路径 = **稳定数值地板** + **页温度敏感的字符串比较覆盖层**；后者与 trigram 共享冷缓存根因（串/SoA 页驻留），只是暴露面不同（trigram 散落候选行波动 700×，full-eval 顺序串池波动 1.3–1.7× 但绝对值更高）。**mlock/madvise P0 同治两者。**

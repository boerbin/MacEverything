## 3. 本轮头条：广域冷轮——多区同时冷化（对照 R85/R86 单区冷）

`hello world` 逐候选成本飙到 63060ns（R86 的 ~5 倍），`*.swift` 整体从 10ms 涨到 108ms，`MacEverything` 的 trigram 索引页自身冷化（trig 33.65ms）。这不是某条路径的问题，而是**工作集被 OS 大面积换出**（疑似外部内存压力 / 周期性页回收），导致跨区同时冷化。

与 R85/R86 的"单区随机换出"互补：页温度既可逐区独立演化（R85↔R86 对调），也可被全局事件一次性整体压冷（R87）。两种模式同源——都由 OS 页缓存驻留决定，且当前**无任何 mlock 保护**。

## 4. 绝对二层分裂：14/14 不破（本轮为最严苛测试）

- **数值层**：size 12.30、dm 11.61 → 最高数值 **size 12.30**

- **间隙 = 29.64 / 12.30 = 2.41×**，无重叠。

**为什么本轮是最严苛测试**：广域冷下**数值层自身也被冷化**（size 升到 12.30，本轮数值高位），间隙因此被压到历史最窄 2.41×。但即便如此，**被冷化的数值层（12.30）仍稳稳低于被冷化的字符串层最低值（29.64）**。这证明二层分裂不是"数值恰好暖、字符串恰好冷"的样本巧合，而是**机制级的恒定差**——纯数值比一列 i64、零解引用的固有成本，永远低于字符串解引用散布串池的固有成本，无论双方冷热如何同步波动。
